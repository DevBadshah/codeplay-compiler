## ✨ Features

### 🌟 **Supported Languages**
- **HTML5** - Live preview with instant rendering
- **CSS3** - Visual styling with preview
- **JavaScript** - Full ES6+ support
- **Python 3.10** - Runs via Pyodide
- **PHP** - Simulated execution

### 🎯 **Core Features**
- ✅ **Live Preview** - See results as you type
- ✅ **Console Output** - Debug with real-time console
- ✅ **Syntax Highlighting** - Language-specific colors
- ✅ **Auto-save** - Code saved in browser
- ✅ **Keyboard Shortcuts** - Fast workflow
- ✅ **Mobile Responsive** - Works on all devices
- ✅ **No Installation** - Single HTML file
- ✅ **Offline Support** - Works without internet

### 🚀 **Quick Start**

1. **Download** the `codeplay.html` file
2. **Open** in any modern browser
3. **Select** a programming language
4. **Write** your code
5. **Run** with one click
6. **See** live results instantly!
